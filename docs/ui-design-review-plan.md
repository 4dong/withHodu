# Anti-paper UI 현황 평가 및 검수·수정 계획

작성일: 2026-09-11

## 목표와 범위

깔끔하고 둥근 인상의 연구·문서 작업 앱. 밝은 중성 배경, 흰 표면, 부드러운 모서리, 절제된 파란 강조색으로 논문과 문서 읽기에 집중시킨다. 학술 논문 검색·서재·대역 리더와 자기소개서 작업실을 함께 다룬다.

이번 산출물은 소스 기반 평가와 실행 계획이다. 앱 구현은 변경하지 않았다. 저장소의 기존 미커밋 변경을 보존한다. Streamlit 안에서 개선하는 것을 기본으로 하며 프레임워크 교체는 범위에 포함하지 않는다.

화면당 주 작업 영역에는 가장 중요한 동작 하나를 파란색으로 강조한다. 삭제는 더보기 또는 관리 영역으로 분리하되 기존 확인 절차를 보존한다. 이모지는 브랜드나 빈 상태 등에 제한적으로 사용하고 반복 컨트롤은 일관된 아이콘과 짧은 한글 이름으로 정리한다.

## 화면별 수정안

1. **공통 프레임·사이드바:** 작업공간 전환을 상단에 두고 현재 위치를 명확히 표시한다. 탐색과 설정을 분리한다. 모델·키·프롬프트·캐시 항목은 설정 안에서 그룹화한다. 현재 선택값은 필요한 위치에서 요약 표시한다.
2. **논문 검색:** “논문 검색” 제목과 검색 입력을 중심으로 구성한다. 예시 질문은 보조 요소로 낮추고 결과는 제목 → 저자·연도 → 요약 → 열기·저장 순으로 정렬한다. 검색 중·결과 없음·오류 상태를 같은 영역에서 보여준다.
3. **서재:** 컬렉션 탐색과 최근 논문을 먼저 보여준다. 보고서 수는 작은 요약 영역으로 줄인다. 긴 제목은 목록에서 제한해도 상세에서는 전체 확인할 수 있게 한다. 선택된 항목이 있을 때 일괄 작업을 표시한다.
4. **대역 리더:** 원문·번역의 기존 대응과 하이라이트를 보존한다. 상단에 뒤로·페이지 번호·이전/다음·보기 설정을 배치한다. 넓은 화면은 대역 보기, 좁은 화면은 원문/번역 전환을 제공한다. 채팅 열기 버튼을 항상 찾을 수 있게 하고 문서 위 덮임을 제한한다.
5. **자기소개서:** 제목은 “자기소개서 작업실”, 기술 용어는 도움말로 옮긴다. “보관함 / 자료 추가 / 전사 검수 / 근거 검색 / 문체 편집”의 목적을 분명히 하고 설정·백업을 분리한다. 전사 검수는 이미지와 편집 본문을 넓게, 문서별 보조 버튼은 더보기로 정리한다.

## 검수 체크리스트 — 모두 Planned

- 화면 크기: 1440×900, 1280×800, 768×1024, 390×844. 추가로 200% 확대 상태에서 주요 동작 접근 확인.
- 화면 상태: 검색 전/중/결과/결과 없음/오류, 서재 0·1·다수 항목 및 긴 제목, 번역 전/중/실패/완료, 채팅 열림/닫힘, 자소서 전사 검수 대기/완료.
- 시각: 제목·본문·보조 정보 위계, 모서리 규칙, 패딩, 버튼 높이, 아이콘 정렬, 카드 내부 액션 위치를 동일 조건의 전후 캡처로 비교.
- 반응형: 페이지 전체 가로 넘침 없음, 좁은 화면에서 탭·입력·채팅·문서 도구 잘림 없음. 문서 자체 확대 스크롤은 페이지 전체 넘침과 구분.
- 키보드: Tab 순서, 포커스 표시, Enter/Space 활성화, 패널 닫기와 포커스 복귀, Cmd/Ctrl+C, 입력 중 페이지 단축키 오작동 여부.
- 터치: 호버 없이 페이지 이동·채팅 열기·주요 작업 가능, 스크롤과 문단 선택 간섭 없음.
- 대비: 렌더링된 본문·보조 글자·버튼의 실제 색상으로 대비를 측정. 프로젝트 합격 목표는 일반 텍스트 4.5:1 이상. 아직 측정하지 않음.
- 모션: OS 모션 감소 설정에서 사용자 정의 반복·이동 효과가 줄어드는지 확인.
- 기능: 검색·서재 열기·페이지 이동·재번역·하이라이트 고정·복사·내보내기·작업공간 왕복을 검수. 외부 API는 샘플/모의 응답으로 UI부터 검수하며 실제 호출 검증 여부는 별도로 기록.
- 자료 보존: 삭제·이동·백업 등은 격리된 검수 자료로 확인. 실제 보관 자료에 대한 삭제 실험 금지.
- 변경별 회귀: 공통 스타일은 화면 검수 중심. 리더 로직을 수정하면 기존 `tests/test_visual_highlighter.py`, `tests/test_math_formatter.py`, `tests/test_retranslation_cache.py` 중 영향 있는 테스트를 실행. 자소서 로직을 수정하면 대응하는 `tests/essay/` 테스트를 실행. 기존 실패와 변경 유발 실패 구분.
