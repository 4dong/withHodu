# 🍎 애플(Apple) UI/UX 디자인 철학 및 웹/앱 인터페이스 구현 청사진 (apple_design.md)

---

## 1. 🌟 애플 디자인 시스템의 3대 핵심 기둥 (Three Core Pillars)

애플의 휴먼 인터페이스 가이드라인(HIG)과 최신 웹/macOS/iOS 디자인 언어는 아래 3대 핵심 원칙에 기반합니다.

```
                  ┌─────────────────────────────────────┐
                  │    애플 UI/UX 3대 디자인 기둥       │
                  └─────────────────────────────────────┘
                                     │
         ┌───────────────────────────┼───────────────────────────┐
         ▼                           ▼                           ▼
  1. 명확성 (Clarity)         2. 겸손 (Deference)         3. 깊이감 (Depth)
  • SF Pro 타이포그래피       • 콘텐츠 중심 프레임       • 다층 레이어 구조
  • 한눈에 들어오는 위계     • 불필요한 장식 배제       • 글래스모피즘 & 그림자
  • 직관적인 시각적 기표     • 여백을 통한 집중도       • 부드러운 스퀘어클 곡률
```

### 1) 명확성 (Clarity & Readability)
* **타이포그래피 중심 위계**: 본문(15~16px, line-height 1.5), 섹션 헤더(18~20px, Bold), 히어로 타이틀(26~32px, Heavy)로 크기와 두께를 명확히 구분합니다.
* **불필요한 인지 부하 제거**: 하나의 카드나 섹션에는 오직 하나의 주 목적(Primary Goal)만 부여하며, 보조 액션은 은은한 서브 톤으로 배치합니다.

### 2) 겸손 (Deference & Content-First)
* **UI는 콘텐츠를 돋보이게 하는 액자**: 화려한 UI 프레임이 주연이 되지 않고, 실제 데이터(논문 표지, 보고서 내용, 텍스트)가 가장 먼저 눈에 들어오도록 설계합니다.
* **여백의 적극적 활용 (Breathable Spacing)**: 빽빽한 배치 대신 충분한 마진(1.2rem~2rem)과 패딩을 주어 시각적 피로도를 없앱니다.

### 3) 계층적 깊이감과 공간감 (Depth & Spatial Hierarchy)
* **다층 평면 레이어링 (Layered Surface)**:
  - Base Canvas (`#f8fafc` / `#ffffff`)
  - ↳ Sanctuary Zone Container (은은한 배경 틴트 + 미세 테두리)
  - ↳ Interactive Cards (소프트 그림자 + 라운딩)
  - ↳ Modals & Popovers (글래스모피즘 + 포커스 링)
* **연속 곡률 (Continuous Squircle Radius)**: 인위적인 원형 모서리가 아닌, 자연스러운 곡률(`border-radius: 16px~24px`)을 부여합니다.

## 2. 🎨 시각적 디자인 토큰 규격 (Design Tokens)

| 구분 | 사양 및 CSS 값 | 사용 목적 |
| :--- | :--- | :--- |
| **Primary Color** | `#0071e3` (Apple Royal Blue), `#2563eb` | 핵심 CTA 버튼, 활성 탭, 주요 링크 |
| **Background Canvas** | `#ffffff` (Canvas), `#fbfbfd` (System Grouped) | 메인 뷰포트 배경 |
| **Zone Container** | `linear-gradient(180deg, #f8fafc 0%, #f1f5f9 100%)` | 독립 서재/보관함 구역 배경 분리 |
| **Border Stroke** | `1px solid rgba(0, 0, 0, 0.08)` / `rgba(226, 232, 240, 0.9)` | 섬세하고 은은한 카드 경계선 |
| **Multi-Tier Shadow** | `0 4px 20px rgba(0,0,0,0.04), 0 1px 3px rgba(0,0,0,0.02)` | 공중에 가볍게 떠 있는 입체감 |
| **Hover Lift** | `transform: translateY(-3px)` (`transition: 0.22s ease`) | 반응형 마이크로 인터랙션 |

## 3. 📐 레이아웃 및 컴포넌트 일체화 규칙 (Component Harmony)

1. **카드 내부 일체형 컨트롤 (Integrated Actions)**:
   * 버튼이나 삭제 아이콘이 카드 바깥으로 튀어나와 줄바꿈을 깨뜨리지 않도록, 모든 액션은 카드 컨테이너 내부 상단(헤더) 또는 하단(푸터)에 100% 너비로 매립합니다.
2. **영구적 확장성을 위한 반응형 대칭 그리드**:
   * 1개, 10개, 50개의 항목이 추가되더라도 레이아웃이 무너지지 않도록 **정형화된 2열/3열 대칭 칼럼(`st.columns`)** 구조를 유지합니다.
3. **완벽한 대칭 (1:1 Symmetry)**:
   * 좌측(AI 인텔리전스 허브)과 우측(서재 폴더 그리드)의 높이 및 여백 비율을 정밀하게 일치시킵니다.

## 4. 🚀 학술 디지털 서재 적용 방안

* **좌측 인텔리전스 허브**: 깊이감 있는 딥 블루 글래스모피즘 카드로 보고서 통계 및 원클릭 열람 지원.
* **우측 연구 폴더 서재**: 테두리 악센트와 부드러운 그림자가 적용된 스퀘어클 폴더 카드 그리드.
* **하단 디지털 책장**: 3D 실물 양장본 표지, 책등 그림자, 우드/메탈릭 책장 랙 렌더링.
