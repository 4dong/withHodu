# 호두 애니메이션 원화 v1

기준: `../hodu-pixel-reference-v1.png` · 제작: 2026-09-14

내장 image_gen으로 한 주제당 4×3 프레임 원화 5장을 생성했다. 도구 출력의 실제 alpha를 보존하고 6% 미만 잔여 alpha를 정리한 뒤, 프레임마다 동일한 중심/접지점으로 평행 이동했다. 개별 프레임의 크기를 따로 늘리거나 줄이지 않았다.

| 이름 | 파일 ID | 프레임 | 재생 시간 |
| --- | --- | --- | --- |
| 걷기 로딩 1 | loading-walk-01 | 12 | 960ms |
| 종이 물고 걷기 로딩 2 | loading-fetch-02 | 12 | 1080ms |
| 책 넘기기 1 | reading-01 | 12 | 2580ms |
| 물기 털기 1 | home-shake-01 | 12 | 2520ms |
| 눈 깜박임·꼬리 흔들기 1 | home-idle-01 | 12 | 3460ms |

## 사용할 파일

- `frames/<ID>/<ID>-01.png` ~ `-12.png`: **개별 투명 PNG, 368×368**. 하나의 파일은 하나의 프레임이다.
- `sheets/<ID>.png`: **정리된 투명 시트, 1472×1104**, 4열×3행. 왼쪽 위부터 행 우선 순서다.
- `previews/<ID>.apng`: 실제 타이밍을 적용한 투명 애니메이션. 미리보기에서는 반복한다.
- `previews/<ID>-contact.png`: 프레임 번호와 시간이 표시된 검수용 기준표.
- `manifest.json`: 순서, 좌표, 기준점, 타이밍, 권장 코드 연결점.
- `source/`: 생성 원본과 실제 사용한 `*-prompt.txt` 5개. 생성 원본의 매우 낮은 alpha 잔여색은 뷰어에서 과장될 수 있으므로 앱에는 정리된 sheets/frames를 사용한다.

## 재생과 연결

화면 60/120Hz와 고유 원화 프레임 수는 다르다. 발걸음은 12프레임/960ms로 진행하고, 화면을 가로지르는 이동은 외부 `.h-walk-dog` 요소에 linear transform을 유지하면 된다. 예전 정적 `.hodu-side`만 이 걷기 시트로 바꾸는 구조다. 이미지 자체를 프레임마다 수평 이동시키면 위치가 두 번 적용되므로 피한다.

독서는 `loading(..., pose="read")`, 종이를 물고 걷기는 `loading(..., pose="fetch")`에 대응한다. 홈은 idle을 기본으로 하고, 물기 털기는 12–20초 정도 간격을 둔 1회 동작 후보로 둔다. 물기 털기의 manifest.loop는 false이며, APNG는 검토 편의를 위해 반복한다. 작업 종료와 움직임 감소 설정에서는 첫 프레임 등 정적 이미지로 멈춘다.

프레임별 고유 동작은 생성된 원화다. 캐릭터의 미세한 털무늬·실루엣 변화가 있으며, 60장의 수작업 프레임 또는 60fps 애니메이션으로 표현하지 않는다. 앱 런타임 적용 완료: 검색·페이지 전환은 걷기, 가져오기·정리는 종이 물고 걷기, 읽기·분석은 책 넘기기를 재생한다. 메인에서는 대기 동작과 물기 털기를 순서대로 재생한다. OS 및 앱의 움직임 줄이기 설정을 지원한다.
